A program that writes one funny line to `/output/entry.txt` — the funniest one-line office joke, judged head to head. An entry for [The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c) on make.fun.

## The line

> My calendar invited me to a meeting about the meeting, and I have never felt so seen — or so doomed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (100 characters, within the 1–199 gate) and nothing else.
